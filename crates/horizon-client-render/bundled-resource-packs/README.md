# Bundled resource packs

`pacp-2.5.4.zip` is the unmodified **Programmer Art Continuation Project 2.5.4** by mzovjn (mzovistired/mzov/jen), with contributors credited on [the project page](https://modrinth.com/resourcepack/pacp). It is All Rights Reserved, separately licensed from Horizon. The fork maintainer confirmed permission to embed this ZIP on 2026-11-03. This does not grant downstream users additional redistribution rights.

The adjacent origin JSON records the original download and upstream hashes. The game embeds this ZIP, materializes it in `.horizon-cache/bundled-packs/`, and exposes the built-in `pacp` selection. Fresh settings select Programmer Art first and PACP above it. Users can disable or reorder PACP through the resource-pack menu. Server packs retain their normal higher priority. An internet connection is not needed to install the embedded pack.
